# Naija Prime Realty

A premier luxury real estate advisory and property showcase platform designed for prime residential and commercial acquisitions across Lagos State, Nigeria.

---

## 🌟 Overview

**Naija Prime Realty** delivers an uncompromised digital experience for high-net-worth individuals, institutional investors, and diaspora clients seeking verified, unencumbered real estate opportunities in Lagos' most exclusive enclaves.

### Key Neighborhoods Covered
- **Banana Island, Ikoyi** — Ultra-luxury waterfront mansions, private jetty docking, and maximum security estates.
- **Old Ikoyi** — Leafy diplomatic boulevards, prestigious high-rises, and prime residential investments.
- **Eko Atlantic City** — Coastal high-rise sky residences, private marina access, and independent infrastructure.
- **Lekki Phase 1** — Contemporary smart duplexes, rooftop plunge pools, and high-yield shortlets.
- **Victoria Island & Oniru** — Grade A commercial towers and boutique waterfront suites.
- **Ikeja GRA** — Sprawling mainland luxury villas and estate parcels near MMA Airport.

---

## 🚀 Key Features

- **Curated Luxury Portfolio**: High-resolution gallery showcases with architectural details, structural features, and amenity breakdowns.
- **Nigerian Title Verification Matrix**: Clear legal verification indicators for every listing (Governor's Consent, Certificate of Occupancy, Gazette, Registered Deed of Assignment).
- **Multi-Currency Converter**: Dynamic instant conversion between Nigerian Naira (₦ NGN), US Dollars ($ USD), and British Pounds (£ GBP).
- **Mortgage & Financing Calculator**: Custom financial planning tool tailored to Nigerian mortgage tenors, equity requirements, and interest rates.
- **AI Property & Investment Advisor ("Adunni")**: Built-in intelligent advisory assistant providing instant answers on Lagos neighborhoods, legal title due diligence, and portfolio recommendations.
- **Inspection Scheduling & WhatsApp Advisory**: Direct 1-click booking workflows and instant agent messaging with pre-configured property parameters.
- **Saved Favorites Wishlist**: Local storage persistence for bookmarking and comparing luxury estates.
- **Minimalist Aesthetic & Motion**: Responsive design featuring smooth scroll effects, interactive hero spotlight carousel, and custom brand cursor.

## 🛠️ Tech Stack

- **Frontend**: React 19, TypeScript, Tailwind CSS
- **Animations & Interactivity**: GSAP (ScrollTrigger), Motion (`motion/react`), Lucide React Icons
- **Backend / API**: Express.js (Node.js) with `@google/genai` AI integration
- **Build Tool**: Vite & esbuild

## 💻 Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

1. Clone or download the repository:
   ```bash
   git clone https://github.com/your-username/naija-prime-realty.git
   cd naija-prime-realty
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. (Optional) Configure environment variables:
   Create a `.env` file from `.env.example`:
   ```env
   GEMINI_API_KEY=your_gemini_api_key_here
   ```

4. Start the development server:
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## 📦 Production Build

To compile the production assets and bundle the backend server:

```bash
npm run build
npm start
```
